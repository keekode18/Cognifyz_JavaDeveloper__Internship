# Cognifyz Java Development Internship

## About

This repository contains the Java projects I completed during my **Java Development Internship at Cognifyz Technologies**.

The projects were completed as part of **Level 1 and Level 2** of the internship tasks.

## Projects

### Level 1

1. **Temperature Converter**  
   Converts temperatures between Celsius and Fahrenheit.

2. **Palindrome Checker**  
   Checks whether a word or phrase is a palindrome while ignoring spaces and punctuation.

3. **Student Grade Calculator**  
   Accepts multiple grades and calculates the average grade.

4. **Random Password Generator**  
   Generates random passwords based on the selected length and character types.

### Level 2

5. **Tic-Tac-Toe**  
   A two-player console-based Tic-Tac-Toe game.

6. **Password Strength Checker**  
   Analyzes password strength based on length and character types.

7. **File Encryption and Decryption**  
   Performs basic file encryption and decryption using a character-shifting technique.
